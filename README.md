# 复核抽样的滚动纠偏与核查出勤简报

数据来自独立设计的合成业务记录，不含真实人员资料。文件为 UTF-8 JSON。

## 资料字典

`frame` 逐周逐分层给总框，`shared_activity` 是参与记录可能相关的共同活动。`draws` 的 `预先随机` 是分层内冻结总体中不放回等概率抽取，`n` 和 `N` 于下达当时固定。`指定核查` 不改变随机记录概率；同一物理段被证实有多份申报时，须能按原抽取集合覆盖该物理段的机会进行解释；如果必要映射不可证实就保留未知。`results` 是相对于某一次抽取单位的核查回执，多个结果不自动作为多次独立抽样。`revisions` 的 `后补` 从已知周进入当期复核范围，不是旧一期冻结总体内的潜在单位；重复行指向同周同层的 `canonical`。`staff` 提供可用的补查时段，访员只能处理服务点所属记录。`release` 给阶段信心水平、可发布分组、区间宽度和每个发布分组的最低确证数；已发布周不是重新编辑对象。

## 读取与核对

使用 Python 3.11。
本地虚拟环境可按 `python3 -m pip install -r requirements.txt` 安装锁定的数值工具。有隔离运行环境时可直接使用已安装版本。

用 `python3 -m json.tool data/records.json` 查看原始记录。用 `python3 -m unittest discover -s tests -v` 核对演练资料的格式及关联。仓库目前只提供资料与输入核对，不提供业务分析结果。
